# Controle de Acesso CIPO 2.0

Aplicação de controle de acesso com frontend e backend independentes.

## Estrutura

- `frontend/`: interface web;
- `backend/`: API e regras de negócio;
- `tests/`: testes automatizados;
- `test_reports/`: registros de testes.

## Desenvolvimento

Instale as dependências e execute a aplicação dentro do diretório apropriado.
O frontend disponibiliza comandos de desenvolvimento, compilação e testes; o
backend contém seus próprios requisitos de execução.

## Segurança

Este sistema deve tratar credenciais e permissões como dados sensíveis. Não
adicione senhas, tokens, chaves ou dados pessoais ao repositório. Antes de uma
implantação, valide autenticação, autorização no servidor, auditoria e a
proteção dos dados processados.

Consulte [SECURITY.md](SECURITY.md) para o reporte responsável de
vulnerabilidades.
