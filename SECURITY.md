# Politica de seguranca

## Dados que nao devem ser versionados

- Arquivos `.env` reais.
- Senhas, tokens, chaves e credenciais.
- Fotos reais de visitantes, frota, carregamentos ou evidencias.
- CPFs, dados de visitantes, funcionarios, motoristas ou terceiros.
- Backups, bancos de dados e relatorios exportados.
- Artefatos internos de agentes ou testes.

## Pendencias

- Limpar historico Git antigo se dados ou credenciais ja estiverem publicados.
- Confirmar se o repositorio deve permanecer publico.
- Rotacionar qualquer segredo que possa ter sido usado fora de ambiente demonstrativo.
